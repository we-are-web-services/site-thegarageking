# waws-wp-site-template

Starter for every new client WordPress build at We Are Web Services. **Do not build a client site in this repo.**
Create a new private repo from it (green "Use this template" button), named for the site, for example `site-<client>`.

What is here:

- `blueprint.json` and `blueprint-store.json`: WordPress Playground blueprints (standard and online store).
- `theme/`, `plugins/`, `content/`: where the site's own code and placeholder content go.
- `docs/`: the workflow, the launch checklist, and a notes file to copy into each site repo.
- `CLAUDE.md`: the rules for a Claude session working in a site repo.

Which plugins a new site gets: `docs/standard-plugins.md` in the **waws-hub** repo (one home; not copied here).
