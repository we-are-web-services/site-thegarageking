# site-thegarageking

Build repo for the new The Garage King website. Built from `waws-wp-site-template`. Placeholder content only; client material stays in Drive.

- `theme/garage-king/`: the block theme (palette, fonts, header, footer, home page sections, one product page).
- `blueprint.json`: WordPress Playground blueprint. Regenerate with `python3 scripts/make-blueprint.py` after changing theme files.
- `docs/brief.md`: what the site should be, from the client's material. `docs/site-notes.md`: decisions and what is not done.
- `CLAUDE.md`: rules for sessions working here.

Preview (repo must be public): `https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/we-are-web-services/site-thegarageking/main/blueprint.json`
